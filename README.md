# Buscador de Perfiles GitHub

Aplicación web que consume la API REST de GitHub para mostrar el perfil de un usuario, 
sus repositorios más recientes, un resumen de los lenguajes más usados, y permite 
paginar los resultados con el botón "Cargar más".

## 🚀 Enlace al sitio publicado
[https://lich-byte.github.io/buscador-github/](https://lich-byte.github.io/buscador-github/)

## 🛠️ Tecnologías usadas
- HTML5
- CSS3
- JavaScript (Fetch API, async/await, URLSearchParams)
- API REST de GitHub

## 📋 Funcionalidades
- Búsqueda de usuarios de GitHub.
- Visualización del perfil (avatar, nombre, repositorios, seguidores).
- Listado de repositorios con opción de ordenar por última actualización o nombre.
- Resumen de los lenguajes más usados.
- Paginación con el botón "Cargar más".
- Contador de peticiones restantes (x-ratelimit-remaining).
